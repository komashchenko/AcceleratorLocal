# AcceleratorLocal

Local crash reporting for Counter-Strike 2, with automatic symbol generation and stack traces.

Only Linux is supported.

## Installation

1. Install [Metamod:Source](https://www.sourcemm.net/downloads.php?branch=dev).
2. Download archive from [Releases](https://github.com/komashchenko/AcceleratorLocal/releases).
3. Stop the server and extract the archive's `addons/` directory into `game/csgo/`.
4. Adjust `addons/acceleratorlocal/acceleratorlocal.ini` if needed, then start the server.

Minidumps and text reports are saved in `addons/acceleratorlocal/dumps/`.
